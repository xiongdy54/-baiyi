# 提示词测试台（prompt-lab，M1.3）

独立最小 Electron 工具，用于在不污染主软件的前提下调优制卡提示词。

## 启动方式（重要）

- 双击项目根目录的 **`启动提示词测试台.bat`**；或
- 在项目根目录终端执行 `npx electron prompt-lab`。

⚠️ **不要用浏览器直接打开 `renderer/index.html`**——页面需要 Electron 的本机接口（AI 配置、图片选择、流式对话），浏览器里没有这些接口，按钮会全部无反应。误开时页面会显示红色指引（而不是静默失败）。

## 调优闭环（用户钦定，v15/v16）

1. **AI 改提示词**：按用户要求在测试台内（左栏编辑器）修改提示词/流程；
2. **用户手动实测**：右栏粘贴文字材料（或选择图片材料）→ 运行管线 → 查看路由、生成卡与 Lint 结果；
3. **用户反馈测试结果**；
4. **决定是否并回主软件**：并回时在主软件中**播种新版本**（旧版留痕），测试台内容不自动写入主软件。

主软件内不做提示词调优试验。

## v4 候选补丁（2026-09-09，待实测）

`prompts-draft.js` 是当前调优候选（主软件仍为 v3 不动），已按覆盖核对报告落实：

- **G4** card-formula：地标双卡（一句话核心原因 + 直观表示）强制化 + 边界三问至少其一；
- **G5** 新增 R18 数字克制（一卡 ≤1 个必要数字，配助记锚）；
- **G6** 新增 R19 观点归属（争议结论记「X 声称…」）；
- **G7** R2 等价答案宽容 + R5 部分枚举标注合格线（card-enum 同步）；
- **G8** 首轮克制、多轮递进（首轮 5-10 张关键卡，标注后续补卡方向）；
- **G9** 退出红线（提不出 3-5 个好问题就一张别产）；
- **card-literature（新增候选）**：文学/诗歌背诵制卡——续写卡骨架（统一上下文窗口）、开头优先、措辞选择卡、原文改进卡（0-2 张）、高层次观察卡（须有可对照答案）、放过标点、名言引用必署名。研究依据见 `docs/M1-prompt-coverage-report.md` §五。
- **G10** 每卡挖空 ≤2 处维持不变（用户拍板）；**G11** 词汇类归 M7；**G12** 图片作答案/题面进可选池。

左栏每个模板有三个状态：`主软件 v3 基线` / `v4 候选（测试台）` / `已修改（本地）`；与主软件不同的模板带 ● 标记。按钮：「保存修改」（存本地）、「应用 v4 候选补丁」（覆写为候选版）、「还原为主软件 v3 基线」。未手改的模板在测试台升级后自动带上 v4 候选。

## v8 候选（2026-10-06，批 F：AI 建议标签 suggestedTags，待实测）

`prompts-draft.js` 恢复显式覆盖模式：在制卡主提示词上打两处字面锚点补丁（DRAFT_TAG=`v8-candidate-suggestedTags-20261006`），制卡族 10 个 card-* scope 全部生效（公式/序列/枚举/文学等内嵌主提示词，自动一致）：

- **输出 schema**：`cards[]` 每张卡新增 `"suggestedTags"` 字段（0-3 个组织用标签，可为空数组）；
- **契约段**（插在输出格式前）：标签＝用户自造的组织/筛选词（考研/错题/口试…），不是学科（domain）也不是知识点（knowledgePoints）；能想象出用户的筛卡场景才建议，宁缺毋滥；每卡 ≤3 个、单个 ≤12 字、层级 ≤2 层、段内禁半角冒号；禁空泛词与卡面复述。

测试台结果卡新增「建议标签：#tag」展示行（仅展示——测试台不落库）。

**实测确认清单（用户逐项看）**：
1. 建议的是「组织词」（考研/错题/口试/待重读这类），不是「心理学」「记忆」这类学科/语义词（那是 domain/知识点的活）；
2. 是否克制（不每卡都硬塞 3 个、无关材料给空数组）；
3. 规范合规（≤12 字、层级 ≤2、无半角冒号——违规即 CardLint L17 会报）；
4. 稳定性（同一材料多跑几次，建议是否漂移；可用「×N 次离散度」运行）。

确认后并回主软件：播种 v8（`ensurePromptTemplates` 制卡族 TARGET_VERSION 6/7→8，旧版留痕）+ GUIDE §6.3/§7.4 登记 + 确认面板勾选 UI（**默认不勾选**断言，D94 §7 批 F）。**批 F 的确认面板 UI 同受标签总开关 `app.tagsEnabled`（v48.63/D107）约束。**

## 隔离边界

- AI 配置存 `%APPDATA%/prompt-lab/ai-config.json`，与主软件完全独立（首次使用需在「AI 配置」里贴一次 Key）。
- 提示词编辑存 `%APPDATA%/prompt-lab/prompts.local.json`；「还原为主软件 v3 基线」按钮从 `electron/prompts.js` 重新复制。
- 测试台不写主软件数据库；card-occlusion/多模态链路同样可测（需多模态模型如 GLM）。

## 管线复刻范围（§4.3）

材料类型路由（cards.ts `detectMaterialType`）→ 取模板（本地 prompts.local.json）→ 上下文打包（材料+来源标记）→ 流式生成（主进程 chatStream，Key 不进渲染层）→ JSON 容错（cards.ts `extractJson`）→ CardLint（cards.ts `lintCard`）→ 结果展示。AIGenBatch 留痕与入库步骤在测试台中省略。
