# 导图 v2 基准：操作说明（给非技术用户）

这个页面用你自己的 AI Key，实测「材料导图 v2」的速度、用量和结构质量。全程只在本机运行，不会改动主软件的数据。

## 一次完整测试

1. 双击项目根目录的 `启动提示词测试台.bat`，等「提示词测试台」窗口出现。
2. 第一次使用：点右上角「AI 配置」，填 Base URL、模型名、API Key，点「保存配置」（这里的配置和主软件是分开的，需要单独填一次）。
3. 点页头的「导图 v2 基准」，会弹出新窗口。窗口顶部会显示当前使用的模型，确认是你想测的那个。
4. 载入材料，三选一：
   - 点「载入示例」（一篇约 1,500 字的《√2 与第一次数学危机》，最适合先试）；
   - 点「载入文件」选 txt / md / docx / epub；
   - 直接把文字粘贴进文本框，标题可填可不填。
5. 点「运行」。左侧汇总、中间结构树会实时出现；节点后面的 `+` 表示可以深挖。
6. 点几个 `+` 试试深挖；点任意节点，右侧会显示原文，还可以点「explain」看一段说明。
7. 看左下角「汇总」：绿色表示达到设计目标，红色表示没达到，灰色表示这次没有足够数据。

## 换模型再跑一次

回到主测试台窗口，点「AI 配置」改模型名（或 Base URL / Key）并保存，再回到基准窗口点「刷新模型」，确认顶部显示的是新模型，然后重新点「运行」。每次运行都会自动记入历史。

## 看历史、对比、导出

- 页面最下方「历史」表列出所有运行（时间、材料、模型、墙钟、TTFN、token、节点数、丢弃率）。
- 勾选两条，点「并排对比所选」。
- 点「导出 CSV」选保存位置（勾选了就只导出勾选的，没勾就导出全部）。会生成两个文件：`xxx.csv`（每次运行一行）和 `xxx-calls.csv`（每次调用一行）。

## 请把这些发回来

- 导出的两个 CSV 文件；或者
- 汇总区和历史表的截图，并说明用的是哪个模型。

## 常见问题

- 提示「未配置 Key」：到主测试台窗口的「AI 配置」里填 Key。
- 某个框架块显示「出错」：多半是网络或额度问题，点「运行」重试即可；失败的调用也会记入历史。
- 历史数据保存在本机用户数据目录的 `mindmap-v2-bench.jsonl`，不在项目文件夹里。
