第 2 章 · 记忆与提取

2.3　提取练习效应

学习者在记忆活动中的主动提取，远比重复阅读更能巩固长期记忆。Roediger 与 Karpicke（2006）的经典实验将被试随机分为两组：一组反复阅读同一篇科普短文，另一组在阅读后进行 free recall 提取练习。一周后的测验显示，在同等学习时间下，提取练习组的保持率比重复阅读组高出约 50%。这一现象被称为「提取练习效应」（testing effect），也常译作「测试效应」。

提取之所以有效，是因为每一次成功的提取都会重构记忆痕迹，并使相关神经通路得到再一次的强化。换言之，遗忘并不可怕——适度的遗忘恰恰为提取制造了必要的难度，这正是 Bjork 所提出的「必要难度」（desirable difficulty）理论的核心主张：让学习过程显得更吃力的条件，往往带来更持久的保持。

值得强调的是，提取练习的效果并不依赖于测验的评分方式。即便是没有反馈的低 stakes 自测，也显著优于被动重读。对渐进阅读的启示在于：复习卡片应当被设计为一次「提取尝试」，而非一次「重读确认」——先回忆，再核对答案，让间隔安排出来的遗忘成为练习的一部分。
