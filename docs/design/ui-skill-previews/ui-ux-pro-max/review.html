问题 · 摘录复习

间隔效应（Spacing Effect）指的是什么？为什么「间隔复习」比「集中重复」更有效？

来自《学习科学：原理与应用》第 2 章 · 位置 31% 点击卡片或按 空格 显示答案

答案

在总学习时间相同的前提下，把复习分散在多个时间点（间隔复习）比集中在一次完成（集中重复）能产生更好的长期留存，这一现象即间隔效应。

原因有二：其一，间隔引入了轻度遗忘，使下次提取带有适当的提取困难，成功提取后的记忆增益更大；其二，分散的重复在不同语境中重建提取线索，形成更多样的记忆通路。艾宾浩斯的遗忘曲线表明最初遗忘最快，因此间隔应随稳定性增长而逐步拉长——这正是 FSRS 调度的核心思想。
