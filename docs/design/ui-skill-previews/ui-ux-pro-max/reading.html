遗忘曲线与间隔效应

如果学习的时间总量相同，把它摊开在数天里完成，几乎总是比集中在一天里更有效。这一结论被称为间隔效应（Spacing Effect），是学习科学中最稳健的发现之一。

1885 年，艾宾浩斯以自己为被试，用无意义音节测量记忆随时间的衰减，绘制出第一条遗忘曲线：记忆在最初数十分钟内下降最快，随后趋于平缓。但后续研究者发现，遗忘并不等于删除——记忆的消退更多是提取线索的衰减，而每一次恰当时机的重新接触，都在重建这些线索。这正是间隔复习起作用的认知基础。

2.1 间隔如何被度量

间隔效应中的「间隔」通常以保留间隔比（retention interval ratio）来刻画：复习间隔应约为目标保持期的 10%–20%。打算记住一年，就把复习散布在数周到数月之间；只为应付三天后的考试，间隔则应压缩到数小时。

「重复触达的时机，比重复触达的次数更能预测长期留存。」——Cepeda et al., 2006

2.2 从曲线到调度

现代间隔重复系统（如 FSRS）把遗忘曲线参数化为个人的记忆稳定性函数：每一次成功提取都会提高稳定性，从而拉长下一次的最优间隔。调度器不追求「永不遗忘」，而是在遗忘临界点附近安排提取，使每一次复习都最大化稳定性的增量。

理解这一点，你就明白为什么「今天已经复习过、明天又排进来」是低效的：过早的重复不产生提取困难，也就不产生记忆增益——这引出了下一章的主题，测试效应。
