第 2 章 · 信息的编码与提取

测试效应：检索本身就是学习

学习科学中最反直觉的发现之一，是「重复阅读」几乎总是被学习者高估。当一页教材被读到第三遍时，主观流畅感会持续上升，而大脑把这种流畅误判为掌握——这就是熟练度错觉。它与真实的记忆保持几乎没有相关，甚至在某些实验中呈负相关。

与之相对，测试效应（testing effect）表明：在没有外部提示的情况下努力回忆一段内容，哪怕回忆失败，也比重读同一页更能巩固记忆。检索不是测量学习的工具，检索本身就是一次强烈的编码事件——每一次成功的提取，都会重塑通往该记忆的通路。

2006 年 Roediger 与 Karpicke 的经典实验让两组学生学习同一篇短文：一组反复阅读四遍，另一组只读一遍后进行三轮自由回忆练习。一周后的测验中， 检索组的成绩比重读组高出约 50%，而重读组的学生对自己的成绩预测反而更高——主观自信与客观收益在这里彻底分道扬镳。

这解释了为什么「先答后看」的笔记法有效：先凭记忆写下你以为的章节要点，再对照原文校准误差——误差本身会成为记忆的锚点。下一次当你觉得复习「很顺」时，请把它当作警告而非安慰。
