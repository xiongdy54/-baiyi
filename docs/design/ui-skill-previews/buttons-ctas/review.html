根据「测试效应」，为什么重读教材的复习效率低于主动回忆？

答案含 3 个要点 · 建议自行比对 卡片 #1042
因为检索是一种编码事件，而非测量工具：
  • 重读只提升流畅感，触发「熟练度错觉」，主观掌握与客观保持脱节；
  • 主动回忆重建提取通路，即使失败也带误差反馈，形成记忆锚点；
  • 实验中检索组一周后成绩比重读组高约 50%，且重读组的自评反而更高。
