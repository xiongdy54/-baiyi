EXCERPT · 01/05
原文摘录 QUOTE
"提取即学习：每一次成功的回忆都会重塑记忆痕迹，使其更不易被干扰和遗忘。当回忆过程费力但最终成功时，记忆痕迹得到最大程度的巩固——这就是所谓的'合意困难'。"
我的笔记 NOTE
这解释了为什么复习卡片必须"先回忆、后揭示"：被动重读卡面等于绕过了合意困难。对应到 FSRS 流程——评分"困难"反而可能是好事，说明提取发生在遗忘边缘，巩固收益最大。可关联：间隔效应（§2.3）、测试效应元分析（P.48）。
