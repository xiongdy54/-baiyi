Chapter 02 · 记忆的编码与提取

2.2 提取练习：测试即学习

当学习者尝试从记忆中提取信息时，发生的不只是"检验"——提取行为本身就在改变记忆。这一节我们讨论提取练习为什么有效，以及如何在阅读实践中使用它。

传统的观点把测验看作学习的"温度计"：它只测量学到了多少，而不改变学习的总量。但过去二十年的实验证据一致表明，提取即学习：每一次成功的回忆都会重塑记忆痕迹，使其更不易被干扰和遗忘。Roediger 与 Karpicke 在 2006 年的经典实验中，让两组学生学习同一篇短文：一组反复阅读，另一组阅读后进行自由回忆测试。一周后的测验里，测试组的保持量显著高于重读组，尽管前者在学习阶段接触文本的次数更少。

这一现象被称为"测试效应"（testing effect）。值得注意的是，测试效应的强度与提取的难度呈正相关：当回忆过程费力但最终成功时，记忆痕迹得到最大程度的巩固——这就是所谓的"合意困难"（desirable difficulty）。过于容易的提取，例如刚读完就回忆，几乎不产生巩固效果；而间隔安排的提取练习，因为强迫记忆在部分遗忘后重建，反而带来了最强的长期保持。

对渐进阅读的启示是直接的：复习卡片不应该被当作被动的"查看"，而应当始终先尝试主动回忆，再揭示答案。接下来的 2.3 节将说明，如何用间隔调度算法把合意困难安排在最恰当的时机。
