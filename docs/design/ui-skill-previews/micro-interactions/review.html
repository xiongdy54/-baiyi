为什么"合意困难"（desirable difficulty）能增强长期记忆，而轻松流畅的重读反而不能？
来源：学习科学 › 第2章 › 2.2 提取练习（P.49） 按 空格 显示答案
答案 ANSWER点击下方评分按钮完成本次复习
提取的费力程度与巩固收益正相关：费力但成功的回忆迫使记忆痕迹在部分遗忘后重建，形成更抗干扰的编码。
流畅的重读只提供"熟悉感"，没有触发重建，因此即时感觉良好、长期保持很差——这正是重读比提取练习效果差的原因。
