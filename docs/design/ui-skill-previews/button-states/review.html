问题 卡 #2047 · FSRS 稳定性 6.2 天

与被动重读相比，为什么「提取练习」能更有效地巩固长期记忆？请从记忆痕迹的角度说明。

空格 显示答案
答案
  • 提取行为本身是一次「记忆修改事件」：每次成功提取都会重建记忆痕迹，使其更清晰、更抗干扰。
  • 重读只提升「流畅感」，加工深度远低于一次费力的主动回忆，对长期保持贡献很小。
  • 提取难度具有「合意困难」性质：越费力，记忆增长越大——这正是间隔复习有效的原因。
