提取练习与测试效应

绝大多数学生的学习策略是反复阅读：一遍遍地翻看教材、用荧光笔划出重点、在考前把笔记再读一遍。然而，认知心理学在过去半个世纪里积累的证据指向一个反直觉的结论——重读带来的「熟悉感」并不等于记忆。流畅的错觉让人安心，却几乎不产生长期保持。

Roediger 与 Karpicke（2006）的经典实验让两组学生学习同一篇科普短文：一组反复阅读四遍，另一组只读一遍后进行自由回忆测试。一周后测量保持量，测试组比重读组高出约 50%。这就是「测试效应」（testing effect），也称提取练习（retrieval practice）：衡量学习的不是输入了多少，而是能提取出多少。

提取为什么有效？关键在于，每一次成功的提取都是一次记忆的重建。每当你从记忆中主动提取一条信息，这条记忆痕迹就会被重新巩固一遍，变得更清晰、更不易受后续干扰。而重读只是让材料「看起来更眼熟」，加工深度远远不及一次费力的回忆。

值得注意的是，提取的困难程度本身具有「合意困难」（desirable difficulty）的性质：提取越费力，记忆增长越大。这也是间隔复习优于集中复习的原因——间隔拉长之后，提取变得更难，练习因此更有效。
