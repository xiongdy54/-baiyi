原文

同样的总时长，分散在多天的学习组在两周后的保持测验中，成绩比集中学习组高出约一倍。间隔之所以有效，是因为它迫使记忆在「稍微遗忘」之后被重新提取——提取时遇到的困难越大，只要仍然成功，记忆被改写的幅度就越大。

—— 《学习科学：基础与研究》第 41 页
我的批注

间隔效应和上一章的生成效应是一体两面：提取本身就是一次「生成」，而间隔保证提取发生在遗忘临界点上，生成难度恰到好处。复习时先凭记忆复述本段，再翻开原文核对，不要直接重读。
