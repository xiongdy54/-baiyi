什么是「合意困难」（desirable difficulties）？它与单纯的「学习吃力」有什么本质区别？

凭记忆作答后，再对照背面要点。按 空格 显示答案

背面 · 参考答案第 8 张，共 44 张

合意困难指在学习当下降低表现、却能提升长期保持与迁移的特定困难，如提取练习、间隔安排、变换练习情境。它与「难」的区别在结果指向：

  • 合意困难牺牲当次成绩，换来两周后的保持；无效困难只是让当下更费力，保持不变。
  • 判断标准是提取是否仍然成功——踮起脚够得着；彻底失败则不构成「合意」。
