记忆的编码与提取

2.3 提取练习

大多数学习者默认的学习方式是重复阅读：把同一章内容从头到尾再看一遍，划线、抄写、再做一遍笔记。这种方式带来一种熟悉感——文字越读越顺，于是我们推断自己已经掌握了它。但熟悉感衡量的是识别的难易，而不是未来能否提取。

提取练习的思路正好相反：合上书，凭记忆回答「这一节讲了什么」。每一次成功的提取都是一次重新编码，它比再次输入同样的信息更能巩固记忆轨迹。（Roediger & Karpicke, 2006）

在经典实验中，两组学生学习同一篇说明文：一组重复阅读四遍，另一组只读一遍、然后做三次自由回忆。一周后的保持测验中，提取组的成绩比重复阅读组高出约百分之五十，而学习者的事前预测恰好相反。这个落差被称为「提取练习的元认知错觉」。

值得注意的是，提取练习并非万无一失。当提取总是失败——材料过难、提示不足、间隔太长——反复测试本身既浪费时间，又巩固了错误的答案。设计提取练习的关键，是让提取「踮起脚够得着」。这句话是本节唯一的操作建议，值得摘录。

2.4 间隔效应

把同样的总学习时长分散到多天，保持成绩几乎总是优于集中学习。艾宾浩斯在十九世纪就记录到了这一现象，此后一百多年里它在从音节列表到外科手术培训的所有任务上被反复验证。间隔起作用的机制，与「稍微忘记一点再提取」有关：提取时遇到的困难越大（只要还能成功），记忆被改写的幅度就越大。

这正是本软件调度复习时遵循的原则：每次复习都安排在你即将遗忘的临界点上，而不是在你还记得牢固的时候。
