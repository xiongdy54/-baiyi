# 阅读翻页与默认排版精修（D241 / v49.70）

## 范围与取舍

- 保持 foliate 内核与 iframe / CSS 多栏布局，不引入依赖、不改数据库或 IPC，不改变 PDF 固定版式。
- 不在外层套原生 CSS `scroll-snap`：章节内容在 iframe 内动态分栏，跨章还需异步卸载/加载；外层滚动容器没有对应每一页的 DOM 吸附点。直接沿用 paginator 的页坐标与章节导航，提供 Scroll Snap 式的跟手、阈值吸附、短拖回弹。
- 只增强阅读内容导航，不改变顶层页签过渡契约。

## 翻页行为

| 场景 | 行为 |
| --- | --- |
| 分页 / 对开，按钮或键盘 | 滚动坐标与 relocate 立即落在目标页，内容以 WAAPI transform 滑行到位；连按从当前视觉位置续滑 |
| 横向触控板 | 跟手，超过页宽 16% 或速度阈值吸附一页；不足阈值停手回弹；目标页按手势起点计算，避免大幅单次事件跳两页 |
| 竖向滚轮 | 一次手势只翻一页；停顿或重新发力开始下一手势，惯性不连翻 |
| 滚动模式整屏翻页 | rAF 缓动，保留约 1.5 行上下文重叠；连按按上一目标续翻，滚轮 / 触摸可接管；promise 在 relocate 更新或取消后完成，输入锁不阻塞下一次翻页 |
| 章节边界 | 先淡出微移，再换章并淡入；触摸吸附共用同一路径；书首书尾守卫，不进入空白边页或加载无效章节 |
| 滚动模式章界 | 到边界的惯性不直接穿章，停顿后明确续滚才加载下一章 |

时长与曲线统一读取 `src/theme.css` 的 `--reader-turn-*`，定义见 `MOTION-DESIGN-SPEC.md` §1.1。销毁时清理动画、缓动与滚轮计时器。

## 默认排版

- 修复旧 `JSON.stringify(整串字体栈)` 把多个字体误当单一字体名的缺陷；逐项清洗并引用字体名，通用字体族保留关键字。
- 缺省字号 **18px**；中西文衬线栈优先使用思源 / Noto Serif CJK，随后 Iowan / Charter / Georgia 与系统宋体 / 明朝体回退。
- 默认字体栈下，章节根语言选择日文、繁中或韩文地区字形。只改根字体的继承，不把语言选择器应用到每个元素，避免覆盖代码等宽字体或出版方字体。
- 默认段距 0.8em；分级标题、引文细线、列表、代码、横线表与图注采用轻量默认排版；默认内容规则用零特异度 `:where()`，出版方显式样式优先。
- 保持行距 **1.7**、版心上限 **720px**、边距 **48px**；中日韩段落两端对齐，显式英文段落不套用中文对齐规则。
- 颜色从 currentColor 派生，小圆角读取宿主主题 Token，不硬编码阅读主题色。

## 设置与兼容

- `appearance.turnEffect`：`glide`（默认）/ `none`。
- 旧存储 `turnAnimated` 退役并在归一时剥离；同名字段仅作为 `resolveAppearance` 输出，供 adapter 设置 vendor `animated` 属性。新默认动效会覆盖旧字段的开关意愿，用户可在阅读设置中重新选择关闭。
- 系统 `prefers-reduced-motion` 及应用 `motion-off` / `motion-reduced` 优先，关闭生效动效但保留 glide 存储意愿；开着书时偏好变化即时更新，关闭时取消在途动画，不迟到重播。
- 已显式设置的字体、字号、行距、边距和版心保持原值；新字号只影响未设置的用户；摘录卡面若启用「跟随阅读字号」，其缺省字号也同步变为 18px，独立字号与显式值不变。
- PDF 外观和缩放不变，翻页过渡控件继续禁用。
