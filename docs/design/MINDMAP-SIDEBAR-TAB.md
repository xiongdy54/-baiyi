## 0. 用户原话（2026-10-03，逐字留痕）

四、阅读界面侧边栏中的图谱页签：请将顶部工具栏"更多"中"导图"进入后的右侧面板整体移动到图谱页签中。此后，生成导图和查看历史版本的操作都应在图谱页签中完成。并且请去掉"导图"按钮，导图按钮的所有功能都请在图谱页签当中完成，也就是说它生成的导图直接在侧边栏右侧的主界面当中显示，不用再单独跳转到一个全新的界面。

三、打开侧边栏后，摘录和图谱页面呈灰色且点击无反应。即使没有内容，也应允许点击进入页签。这一点也应该与摘录页面的侧边栏一致。

## 1. 契约

### 1.1 呈现宿主：全屏 Overlay → 侧栏页签 + 主区画布层

- **图谱页签**（`data-panel="map"`）＝原全屏工作区**右侧边栏**（`.mindmap-sidebar`）的整体迁入：生成/预览/生成中/评审未通过/节点搜索/节点详情/**历史版本**（任何状态可见）全部区块原样保留，只是宿主从浮动 aside 变为侧栏页签面板。
- **画布**＝原 `.mindmap-canvas`（含顶部动作行：适应窗口 / ± 缩放 / 导出 SVG）挂到**侧栏右侧的主界面**：`MindmapTab` 用 `createPortal` 把画布渲染进 `.reader-engine-main` 内的 `.reader-map-layer` 覆盖层——图谱页签激活时导图直接盖在正文上方显示，**不再打开独立界面**；切页签/收侧栏即回正文，正文引擎全程不卸载、位置天然保留（保留原「内核不销毁」的语义，只是不再需要「正文」返回钮）。
- `MindmapWorkspace.tsx`（全屏工作区）退役，状态机与两块视图重组为 `src/components/reader/MindmapTab.tsx`：`useMindmapWorkspace()` 状态机 hook + `MindmapTab`（页签面板 + 画布 portal）。生成/续跑/深化/评审/取消/版本激活删除等**全部行为与 IPC 不变**。
- 「跳到正文」＝内核跳转 + 收起侧栏（回正文阅读），不再有 onBack 概念；「就此制卡」保持既有 card-structure 链路（AI 面板在右侧滑出，导图保持在场）。

### 1.2 入口收敛

- 工具栏「更多」菜单**删除「导图」项**（只剩 复习摘录 / 复习闪卡）；`data-mindmap-entry` 钩子随之退役。
- 右下角全局指示器「打开导图」（含重启后续跑 `resumeRunId`）改为：打开侧栏并落到**图谱页签**（`openMindmapInitially` 语义不变，落点从全屏工作区改为页签）。
- 原「图谱页签＝mapTree 树形目录」退役：节点跳转由画布选中→节点详情→「跳到正文」与节点搜索承接；`mindmap:mapTree` IPC 与其数据形状**保留不动**（仍有直接调用方与测试）。

### 1.3 页签恒可点（同批第三项指令）

- 侧栏三页签（目录/摘录/图谱）**永远可点**，不再按数据在场性 disabled；空数据进页签显示空态（图谱页签的空态＝导图面板「尚未生成」+ 历史版本区，天然成立）。
- 侧栏入口（展开/收起钮）**恒可用**，删除「数据不在场自动收起」的 effect。
