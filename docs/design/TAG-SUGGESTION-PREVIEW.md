## 全版本共享约束（不随版本变化）

- 数据源不变：词表 = `cards.tags_json` ∪ `extracts.tag_json` 派生（`cards:listTags`），匹配大小写不敏感、层级前缀语义；≤8 项。
- 防泄题不变：复习页仅在答案揭示后出现（R6 同源）；卡面正面永不出现。
- 落库链路不变：建议只是「快捷输入」，选中 = 把该词放入输入草稿，仍走既有确认/保存；AI 不参与（批 F 的 AI 建议标签是另一独立闭环）。
- 瑞士风基线不变：方角、Token 化时长（映射 D88 动效 Token，零新增）、hairline、无彩色承载（强调只走 accent）。
- 键盘与可达性：Esc 恒收起；`prefers-reduced-motion` 全降级（瞬时切换，动效不做功能依赖）。

## V1 幽灵内联补全（Ghost Inline Completion）

交互方式：**不弹任何层**。输入「脑」的瞬间，输入框内光标后以灰色幽灵文字补全首个最佳匹配「脑科学」；`Tab` 或 `→` 接受（幽灵转实字并生成 chip），继续输入则实时重匹配；`↑↓` 不可用（单候选语义）。

```text
┌──────────────────────────────────┐
│ 脑科学│            ← 幽灵字＝灰色 30% 透明度，光标停在最末
└──────────────────────────────────┘
（无浮层、无轨道、零布局位移）
Tab 接受 → [ 脑科学 ×]            ← chip 生成
```

显示方式：候选只活在输入框内；层级路径超宽时幽灵只补「剩余段」。
动效依据：ghost 出现 ≤50ms ease-out（instant-0-100ms：「动画在此速度只做确认不做交流」）；接受时幽灵→实字→chip 三步在 100-150ms 内完成（state-changes 微状态档）。
优劣：最快、零遮挡零位移，注意力恒在输入点（attention-direction：无竞争中心）；但**只给一个候选**，可发现性最差——适合熟练后期的快速打标，不适合「想看看库里有什么」。

## V2 下拉建议列表（现状基线的原则化打磨）

交互方式：输入 ≥1 字，输入框正下方弹出浮层；`↑↓` 导航、`Enter` 选中、`Esc` 收起；首项默认预选（直接 Enter 即加）。

```text
┌──────────────────────────────────┐
│ 脑                               │
└──────────────────────────────────┘
┌──────────────────────────────────┐
│ ▍脑科学            卡 12 · 批注 3 │ ← 预选项：左缘 accent 2px
│  脑科学::记忆       卡 4          │   「脑」前缀 accent 高亮
│  认知脑科学         批注 7        │
└──────────────────────────────────┘
```

显示方式：每项 = 完整层级路径 + 两源计数徽标；**输入前缀在候选项文本内以 accent 高亮**（staging：让「为什么推荐它」可见）。
动效依据：面板 pop-in 140ms ease-out + 自上 3px 沉降（entrance-animations 快速入场档）；项 stagger 20ms、上限 5 项（entrance-animations stagger 公式）；前缀高亮瞬时（instant）；选中→chip 120ms（state-changes）。
优劣：信息最全（计数/来源/层级），键鼠双通道；占垂直空间，复习页 meta 区需要留白配合。

## V3 常驻 chip 轨道（Recent + Filter Rail）

交互方式：**没有下拉**。编辑器打开即常驻一条 chip 轨道：未输入时显示「最近使用的 3 个」（一键即加）；开始输入后轨道**实时过滤**为匹配项；点 chip 即加、再点已加的撤回。

```text
┌──────────────────────────────────┐
│ 脑                               │
└──────────────────────────────────┘
[脑科学 ×] [脑科学::记忆 ×] [认知脑科学 ×]  ← 轨道随输入过滤，高度恒定
（未输入时：[最近：考研 ×] [错题 ×] [口试 ×]）
```

显示方式：chip 本体即候选（带计数的小徽标）；已加过的 chip 呈实心态，点击撤回。
动效依据：过滤时保留 chip 以 FLIP 平滑归位、高度恒定禁跳变（state-changes：「列表重排是典型状态变化，双向可逆、去回对称」）；新 chip pop 120ms（micro-interactions）。
优劣：可发现性最好——不输入也看得到库里有什么（attention-direction：轨道是常驻证据，secondary action 不抢输入框主注意力）；代价是常驻占一行。

## V4 展开式面板（Expanding Field）

交互方式：聚焦或输入时，**输入框本体向下生长为一体化面板**（不是浮层——候选区与输入框同底色、连续边框）；候选大行距呈现，`↑↓`/`Enter`/点击皆可，`Esc`/失焦收回。

```text
┌──────────────────────────────────┐
│ 脑                               │ ← 聚焦后 border 先变 accent（预告）
│ ────────────────────────────────│ ← 面板从输入框底边生长（一体，无独立浮框）
│ 脑科学                  卡12 批注3 │
│ 脑科学::记忆            卡4        │
│ 认知脑科学              批注7      │
└──────────────────────────────────┘
```

显示方式：候选 2 行结构（路径主行 + 计数 meta 行），触达面积大；面板即输入框的延伸（一个 silhouette）。
动效依据：`grid-template-rows 0fr→1fr` 200ms ease-in-out（state-changes accordion 模式）；展开前 40ms 输入框 border 先行 accent——先预告后展开（forms-inputs 原则 2「Anticipation：为输入动作做准备」）；收回 140ms，去回对称（state-changes 关键规则）。
优劣：舞台从容、信息层次最好（staging 精神：选择面舞台化、一步完成看-选-加）；布局位移最大，动效实现最复杂。

## V5 命令面板（Command Palette）

交互方式：点「＋标签」不再展开小编辑器，而是弹出**居中命令面板**（backdrop 压暗）：大输入框 + 全宽候选行；`↑↓`/`Enter` 选中后**输入框清空继续输**（一次会话连续加多枚）；`Esc` 关闭；空态首屏直接列「最近使用」。

```text
        ┌────────────────────────────────────┐
        │ 添加标签…                    [Esc]  │
        ├────────────────────────────────────┤
        │ 脑科学                   卡 12 · 批注 3 │
        │ 脑科学::记忆             卡 4           │
        │ 认知脑科学               批注 7         │
        ├────────────────────────────────────┤
        │ ↑↓ 选择 · Enter 加入（可连续） · 已加 2 │
        └────────────────────────────────────┘
```

显示方式：模态隔离（backdrop 隔掉复习页一切竞争元素）；候选行大字号 + 右侧计数；底部快捷键提示行；已加数量实时显示。
动效依据：backdrop 淡入 120ms、面板 scale .98→1 + 160ms ease-out（entrance-animations modal 档：内容 +50ms 跟进）；关闭 100ms ease-in（micro-interactions：出比入快）；选中行即时填充（instant）。
优劣：键盘效率最高、一次多枚、无遮挡与位移顾虑（attention-direction：isolation 到极致）；模态感最重，复习页语境下打断感最强。

## 选型对照

| 版 | 交互方式 | 显示方式 | 布局位移 | 可发现性 | 键盘效率 | 复习页适配 |
|---|---|---|---|---|---|---|
| V1 幽灵补全 | 输入内联 Tab 接受 | 输入框内幽灵字 | 零 | 弱 | 高（单候选） | 最好 |
| V2 下拉列表 | 浮层 ↑↓/Enter | 路径+计数+前缀高亮 | 小（浮层） | 中 | 高 | 好 |
| V3 常驻轨道 | chip 点击即加 | chip 轨道过滤 | 恒定高度 | **最好** | 中 | 好 |
| V4 展开面板 | 输入框生长为面板 | 一体化两行候选 | 大 | 好 | 高 | 中 |
| V5 命令面板 | 模态键盘流 | 全宽候选+快捷键行 | 无（模态） | 好 | **最高**（连续多枚） | 弱（打断感） |

**组合可行性**：V2 为底 + V1 幽灵字叠加（下拉给可发现性、ghost 给最快路径）是常见收尾态；V3 轨道与 V2 下拉互斥（同占输入框下方）。
