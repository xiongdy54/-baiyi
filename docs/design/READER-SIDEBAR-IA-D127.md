# 阅读器侧栏信息架构重排（D127，v48.83）

> 用户 2026-10-11 实机反馈（附截图）：①目录/摘录/图谱三页签排在下方，而只对摘录页签生效的「全部/摘录/高亮/位置/时间」五个筛选排序钮排在它们上面——层级颠倒；②侧栏顶部按钮行与右列「制卡/截图」工具按钮高度未对齐；③收起/展开钮在收起、展开两态下位置不一致。要求按 better-layout / better-typography 重排，页签层级调整后样式同步。排版依据：组间 2× 组内节奏（better-layout）、共享对齐缘、主役页签用全应用既有的「文字 + 2px accent 下划线」语言（顶栏页签同款）、控制件与内容区分。

## 1. 信息架构（自上而下）

```
.reader-sidebar
  ├ 页签行（主役导航）：目录 | 摘录 | 图谱 —— 高 56 与右列工具行同带（8+40+8），左让位 64px 给浮动开关钮
  │   〔D139 修订（§6）：**去定高**，行高改由内距推出（8+24+8+hairline）＝与右列 24 档工具行同带；页签钮 40→24〕
  │   激活态＝顶栏页签同款 2px accent 下划线（非灰底块）；hover＝reader-fg 8% 混色
  └ 页签面板（flex 1）
      ├ 目录：目录列表（不变）
      ├ 摘录：上下文工具行（筛选段 3 + 排序段 2，高 24，3:2 铺满，贴面板顶、hairline 分隔）
      │        + 注解列表（AnnotationPanel showHead=false 不变，列表自带滚动）
      └ 图谱：导图面板（不变）
```

- **层级原则**（better-layout「Order by importance / 控制件与内容区分」）：主导航（页签）置顶；只作用于摘录列表的筛选/排序是**上下文控件**，随摘录页签出现、放列表上方——不再悬浮在页签之上冒充全局控件。
- **筛选/排序行**随页签常驻列表顶部（不随列表滚动）：摘录面板改 flex 列（工具行 flex:none + 列表 flex:1 自滚），hairline 与列表分隔。

## 2. 几何对齐

> **本节为 D127 原始稿（当时现状）；其中「高 40」「页签行高 56」两处数值已被 D139 修订，见 §6。**

- **开关钮 `.annot-toggle.bar-btn[data-reader-sidebar-toggle]`**：`top: calc(48px + var(--sp-2))`、**高 40px**（与 `.btn` 同高）——**两态同位同高**（作废 R4 时代「收起态 56 / 展开态 60」的双轨）。宽 40 不变；左 16 不变。摘录页共用的 `.annot-toggle` 基线（40×24、top 60）不动，仅阅读器实例按 attribute 覆盖。
- **页签行**：`height: 56px`（= 工具行 8+40+8）、`padding-left: var(--sp-16)`（16+40+8 让位浮动开关钮，D85 同一让位 Token）；页签钮高 40、`fs-secondary`。
- 右列 `.reader-engine-controls`（制卡/截图…）不动——对齐由侧栏侧主动靠齐实现。

## 3. 退役

- 侧栏顶部 `.annot-side-head`（筛选/排序行）整体移除；`.reader-side-rail .annot-side-head` 系列覆盖规则（与摘录页轨共享的选择器组拆分，摘录页轨保留）全部退役。
- 页签旧样式（24 高/meta/grey-1 底块选中）退役，换文字+下划线语言。
- `.annot-toggle[aria-expanded="false"]` 的收起态 top 覆盖规则退役（两态同位）。

## 4. 动效与可达性

- 页签 hover 底色 160ms `--ease-out-soft`（既有 token）；下划线瞬切（与顶栏页签同款，不做位移动画）；`role="tablist"/tab/aria-selected` 既有语义保留。
- 收起/展开钮：两态同位——点击热区不再漂移；`aria-expanded` 语义不变。

## 6. 修订（D139，v48.95）：顶部按钮带降到 24 档

> 用户 2026-10-12 实机反馈（附截图）：左侧栏顶部四枚钮（收起 / 目录 / 摘录 / 图谱）**高 40**，同一视觉行右侧的「制卡 / 截图」**高 24**——两套高度并排，左带明显更高；要求把它们降到与右带一致，样式与字号相应调整，且侧栏开合动效要符合 `MOTION-DESIGN-SPEC`。

**实机基线（D139 改动前，`tests/d139-sidebar-band.gui.mjs` 探针实测绝对值）**：页签行 `.tabs` = top 48 / 高 **56**（`height: 56px` 定高）/ padTop 8 / padLeft 64；页签钮 **40** 高（top 56 → bottom 96，13px/400）；右列 `.reader-engine-controls` 高 **40.8**（padTop 8，内容 24）；选区动作钮 `.btn-rail` **24** 高（top 56 → bottom 80，12px）；开关钮 fixed(16, 56) **40×40**；轨过渡 `width 0.12s cubic-bezier(0.2,0,0.38,0.9)`。⇒ 左带底缘 104、右带底缘 88.8，**两带 hairline 差 15.2px**、钮高差 16px。

**改法（四组：页签行 / 页签钮 / 浮动开关钮 / 开合动效——口径＝内距定高 + 同档 token + 同门）**：

| 项 | D127 原值 | D139 值 | 依据 |
| --- | --- | --- | --- |
| 页签行 | `height: 56px` 定高 | **去定高**，只留 `padding: var(--sp-2) var(--sp-2) var(--sp-2) var(--sp-16)` | 定高把「内距+钮+内距」写死；去定高后行高 = 8+24+8+hairline，与右列工具行**逐像素同带**（同顶 48、同底） |
| 页签钮 | 高 40 / 13px / 400 | **高 24**（＝ `.btn-rail` 同档）/ **13px / 400 不动** | 高度带对齐是诉求；页签＝**主役导航**，字号语言与顶栏 `.nav-item` 同族（13px），不随右列 12px 工具钮降档——层级差由字号表达，不由高度并排表达 |
| 浮动开关钮 | 高 40 / 宽 40 / fixed(16, 56) | **高 24** / 宽 40 / fixed(16, 56) 不动 | 24 高在两态下都与右列钮同顶同底；落位由内容带推出（内容带 56–80、中心 68 ⇒ `top 56 + 24/2 = 68` 正中） |
| 轨开合动效 | `--dur`(120ms) `--ease`，**无首帧门** | **`--dur-panel`(240ms) `--ease`**，工具行 `padding-left` **同参**；**补 `[data-rail-anim]` 首帧门** | 轨＝栏/面板（`--dur-panel` 注释即「栏/停靠面板开合」）；与摘录批注轨（同形 280px 轨、R2-C 认定合规）取同一档**且同一道门**；两量必须逐字同 duration/缓动，否则轨缘与让位脱拍（D90 教训）。§7「展开 240 / 折叠 200」的非对称档留给**内容折叠**，整宽轨道位移按 `--dur-panel` 一档 |

**首帧门（D139 补，审查 P1②）**：摘录批注轨自 2026-10-09 起就有「滑动过渡仅在用户点过开关后（`[data-rail-anim]`）启用——进入页面时瞬时落位，不再左→右滑入」；阅读轨此前**没有**这道门（过渡无条件挂在 `@media (prefers-reduced-motion: no-preference)` 内）。而 `Reader.tsx` 的 `openMindmapInitially` effect 会在**挂载后**把 `sidebarOpen` 置真（由右下角指示器进入导图），即存在「非用户手势的 0→280 滑入」路径；本批把 120ms 抬到 240ms 会把该滑入放大 2×。故照抄摘录轨机制：`Reader.tsx` 新增 `railAnimate` 状态、点 toggle 时置真、挂在 `.reader-engine-layout[data-rail-anim]` 上，轨宽与工具行让位**两条过渡同门同参**。

**不动**：`.reader-side-rail.is-closed`（宽 0 / `visibility: hidden`）、280px 轨宽与正文让位、页签激活态语言（accent 下划线）、`--sp-16` 左让位、reduce 双轨（过渡仍只在 `prefers-reduced-motion: no-preference` 内声明，reduce 直切）。

**§5 验收 1/2 的「开关钮 40×40」「页签行高 56」由本节取代**（⑪a3 → 开关钮 fixed(16,56) **40×24**；页签行高改判「与右列工具行等高」）。机制口径移到新套件 `tests/d139-sidebar-band.gui.mjs`（同带/同高/同底 + 两态同位 + 首帧门 + 用户手势真跑过渡 + reduce 双轨【源码口径 + CDP 模拟 reduce 行为】 + 探针自证）。
