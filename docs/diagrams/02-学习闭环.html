INCREMENTAL READING · 算法主线

算法设计思路：渐进阅读闭环

一条闭环、两条不变量：材料 → 摘录 → 队列 → 制卡 → FSRS → 事实 → 推荐 → 新材料；AI 只在中层提议，状态只由证据推断。

摘录与队列

SuperMemo19 式

  • 摘录 = 亲手搁置的最小未理解单元，可挂 shelveReason（缺前置 / 太密 / 缺例子 / 语言）
  • 队列确定性排序：priority ASC，同优先级按 topic_next_at ASC
  • 推迟固定 ×1.6、封顶 180 天（占位；负载感知推迟已降级可选池）
  • 状态机 open → reading → carded → consolidating → resolved，未知状态按 open 前向兼容

知识状态怎么算

证据驱动（K 系列）

  • 每知识点每维度一个 Beta 后验：estimate = α/(α+β)，同时存 confidence 与 evidenceCount
  • 五维：识别 / 回忆 / 概念理解 / 应用 / 迁移；禁止把「Good」直接等于掌握度上涨
  • 总体分用短板聚合（非平均），防同质卡刷满
  • 全部状态可由 knowledge_evidence + review_logs 按模型版本重算

边界与红线

AI 不是事实源

  • AI 永不写 fsrs_json / review_logs / knowledge_evidence
  • AI 提案先进 knowledge_proposals 暂存表，用户确认后才入正式表
  • 关系与知识点永不派生 due / 优先级
  • 推荐禁静默重排队列：只做「推荐面板 + 可选排序开关」
