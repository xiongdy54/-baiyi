算法结构：AI 制卡七步管线

一根管线上只有一步不本地：本地决定类型与提示词，主进程调 LLM，回程立刻用确定性的规则把结果卡住。

七步管线

每一步都可单独验证

  • ① 模式路由（本地正则，同一文本必然同一结果）→ ② 取提示词 + 上下文打包
  • ④ LLM 流式生成（主进程，Key 不与渲染层见面，思考过程经 thinking 信号转发）
  • ⑤ JSON 容错解析：括号平衡扫描，模型在 JSON 后附说明文字也能落回结构化结果
  • ⑥ CardLint L1–L16 + S1 相似查重（n-gram + 编辑距离）→ ⑦ 用户确认入库

为什么先路由再制卡

类型决定提示词分支

  • concept 概念论述 → card-generation（问答，可转两张独立卡）
  • formula 公式推导 → card-formula；sequence 流程 → card-seq
  • enumeration 枚举 → card-enum（挖空）；literature 诗词 → card-literature（逐句续写全覆盖）
  • image 图片材料 → card-occlusion（遮罩归 occlusion_json，形状走几何归一化）
  • 识别结果可手动覆盖，且选单选择按书记忆（settings.app.materialTypes）

质检到底查什么

CardLint 十六则 + S1

  • L1 答案过载 / L2 是否题 / L3 集合问法 / L4 有序枚举未拆解
  • L5 缺上下文前缀 / L6 缺来源 / L13 前缀泄题 / L14 实体疑似缩写
  • L9 单卡挖空 >2 处 / L11 图片挖空卡缺资产（error，阻止入库）/ L16 开放答案缺合格线
  • S1：与已有卡高相似 → 提示可能相互干扰，走 card-contrast 生成对比卡
