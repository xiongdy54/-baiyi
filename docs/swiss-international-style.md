# 瑞士国际主义设计风格 — 软件视觉规范 (Swiss / International Typographic Style)

> 由通用版瑞士风规范(海报/PPT/网页)演化而来,专注**软件界面**(桌面/Web/移动)。整体设计语言不变;针对软件"多界面、多状态、长时间使用"的特性,新增 Token 体系、状态设计、浮层层级、深色模式、可访问性等章节,并修正了仅适用于印刷/海报的规则。海报/信息图/PPT 场景参见姊妹 skill [[guizang-ppt-skill]]。

## 软件设计与海报设计的差异(本规范的改编依据)

| 维度 | 海报/PPT | 软件 UI(本规范) |
|------|---------|------------------|
| 观看方式 | 3 秒远观,冲击力优先 | 长时间近用,可读性与密度优先 |
| 尺寸单位 | vw/vh 随屏缩放 | 固定 px,DPI 无关 |
| 数量 | 单幅 | 几十个界面 → 必须有 Token 体系保证一致性 |
| 状态 | 无 | hover / 焦点 / 禁用 / 加载 / 错误 / 空态 |
| 颜色 | 单幅一个 accent | 全局单一主 accent + 全局统一语义色(见下) |
| 阴影/圆角 | 全面禁止 | 常规表面禁止;浮层允许单层功能性阴影 |

## 设计哲学(违反任何一条,画面瞬间从瑞士掉到 PowerPoint)

1. **单一焦点色** — 同一界面内只允许一个高饱和焦点色;全应用默认共用同一主 accent(受控例外见"焦点色规则")
2. **极致字号对比** — "越大越细,越小越粗";层级靠字号+字重拉开,不靠颜色
3. **无衬线只此一家** — Inter / Helvetica / Noto Sans SC;任何衬线都是错的
4. **直角纯色平面** — 常规表面禁止渐变 / 阴影 / 圆角;唯一例外是浮层阴影与强制圆形控件(头像、开关)
5. **网格至上** — 8px 基线,所有元素吸附网格,左对齐 + 大幅留白做非对称美学
6. **Hairline 是手术刀** — 1px 极细分割线就够,不加粗、不加阴影
7. **克制优于炫技** — 装饰(几何、巨字、色块)只在欢迎页/引导页/空状态透出,工作区保持纯净

## 色彩系统

### 灰阶(跨主题统一,唯一不变的部分)

| Token | 值 | 用途 |
|-------|-----|------|
| `--paper` | `#fafaf8` | 主底色(极浅暖白,**不要**用纯白 #fff) |
| `--grey-1` | `#f0f0ee` | 浅灰底(区块底、hover) |
| `--grey-2` | `#d4d4d2` | 中灰(分割线、border、禁用) |
| `--grey-3` | `#737373` | 暗灰(辅助文字 / meta) |
| `--ink` | `#0a0a0a` | 文字主色(近黑,**不要**用纯黑 #000) |

文字角色 token:primary=`#0a0a0a` / secondary=`#525252` / helper=`#737373` / placeholder=`#a3a3a3`;border-subtle=`#e0e0e0`(1px 发丝线)/ border-strong=`#a3a3a3`。

### 焦点色规则(软件多界面适配 — 核心修订)

软件由几十个界面组成,原"一幅设计一个 accent"改写为三条:

1. **默认:全局一个主 accent** — 所有界面共用,保证品牌一致性。从 4 套锚点色中选一(未知就选 IKB 蓝)。
2. **例外 A:语义色** — 成功/警告/错误是功能信息,不属于焦点色体系,全应用统一、任何界面可用,但只用于状态提示,禁止当装饰或第二 accent:

   | 语义 | 色值 | 用法 |
   |------|------|------|
   | success | `#1A7F37` | 成功提示、完成态 |
   | warning | `#9A6700` | 风险提示、待处理 |
   | error | `#B42318` | 校验错误、破坏性操作 |

   同一界面内的语义色块尽量唯一(有错就只出现红,不要同时挂黄条)。
3. **例外 B:模块色(仅限界面众多的大型产品)** — 最多 4 个固定色,一次性写进 Token,按模块绑定(如"收件箱蓝/报告橙");**模块内仍然只有一个焦点色**,模块色禁止在同屏混用。中小型产品一律用规则 1,不设模块色。

**硬规则**:
- 浅色 accent(黄/绿)上必须用**纯黑**文字,深色 accent(蓝/橙)上用**纯白**
- 产品已有既定品牌色时,可将其规范化为全局唯一主 accent(须与底色达到 AA 对比),Token 化后全应用只用它,不再引入第二种自定义高亮色
- 禁止逐界面临时取色;所有色值必须走 Token
- accent 色块上不要放同色系文字

### 4 套锚点色(只选一套,不允许自定义 hex)

| 主题 | Accent | Accent-on | 适合 |
|------|--------|-----------|------|
| 🔵 克莱因蓝 IKB | `#002FA7` | `#ffffff` | 通用 / AI / 科技 / 设计 / 商业(最经典) |
| 🟡 柠檬黄 | `#FFD500` | `#0a0a0a`(黑字!) | 年轻 / 运动 / 零售 / 消费品 |
| 🟢 柠檬绿 | `#C5E803` | `#0a0a0a`(黑字!) | 生态 / 未来 / Z 世代 / 新兴科技 |
| 🟠 安全橙 | `#FF6B35` | `#ffffff`(建议加粗) | 工业 / 警示 / 运动 / 紧迫感 |

### 深色模式映射(软件必备,海报没有)

| Token | 浅色 | 深色 |
|-------|------|------|
| `--paper` | `#fafaf8` | `#101010`(禁纯黑 #000) |
| `--grey-1` | `#f0f0ee` | `#1c1c1a` |
| `--grey-2` | `#d4d4d2` | `#33332f` |
| `--grey-3` | `#737373` | `#8a8a86` |
| `--ink` | `#0a0a0a` | `#f5f5f2`(禁纯白 #fff 大面积文字) |

- 深色下 accent:浅色 accent(黄/绿/橙)可原样使用;深色 accent(如 IKB `#002FA7`)在深底上对比不足,需提亮同色相变体(如 IKB → `#5B7FE8`),直到与底色对比 ≥ 4.5:1
- 语义色深色下同样提亮一档;阴影在深色下减弱,层次改以 hairline 描边区分
- 深色模式只覆盖色值组 Token,布局/字号/组件规则不变

## 字体系统

### 字体栈

```css
--sans: "Inter","Helvetica Neue","Helvetica","Arial","Segoe UI Variable","Segoe UI",system-ui,sans-serif;
--sans-zh: "PingFang SC","Hiragino Sans GB","Source Han Sans SC","Noto Sans SC","Microsoft YaHei UI","Microsoft YaHei","微软雅黑",sans-serif;
--mono: "JetBrains Mono","IBM Plex Mono","SF Mono","Cascadia Code","Consolas",ui-monospace,monospace;
```

### 软件字号阶梯(固定 px — 替代海报的 vw 体系)

| 层级 | 字号/行高 | 字重 | 场景 |
|------|----------|------|------|
| Display | 40-56 / 1.0 | **200-300** | 欢迎页宣言、KPI 大数字 |
| Title L | 26-28 / 1.2 | 300-400 | 页面主标题 |
| Title S | 18-20 / 1.3 | 400-500 | 区块标题、对话框标题 |
| Body | 14-16 / 1.6 | 400 | 正文、列表主文本(中文行高 1.6-1.7) |
| Secondary | 13 / 1.5 | 400-500 | 描述、次级信息 |
| Meta | 12 / 1.4 | 500-600 | 标签、时间戳、badge、kicker |

**硬规则**:
- 同屏内字号越小的元素字重必须 ≥ 字号大的("越小越粗",灵魂)
- 桌面 Body ≥ 14px,Meta 最低 12px,**严禁 < 11px**;移动端 Body ≥ 15px
- 大标题 `letter-spacing:-.02em ~ -.04em`,`line-height ≤ 1.1`;数字一律 mono + `font-feature-settings:"tnum"`
- 反白大标题内强调字用 `italic + weight 300`,不用 accent 色(同色压同色看不见)
- 欢迎页/引导页的巨幅大字可沿用海报双约束 `font-size:min(Xvw, Yvh)`(Y ≥ X×1.6);工作区内一律固定 px

## 网格、间距与密度

- 8px 基线;数据密集界面允许 4px 半步
- spacing token:`--sp-1` 4 / `--sp-2` 8 / `--sp-3` 12 / `--sp-4` 16 / `--sp-6` 24 / `--sp-8` 32 / `--sp-12` 48 / `--sp-16` 64
- 桌面/Web 用 12 列 grid(`repeat(12,1fr)` + gap 16-24px);移动端 4 列
- 侧边栏固定 200-260px;内容列最大宽度:表单/文档 720-960px,左对齐

### 密度(软件独有)

| 档 | 控件高 | 表格行高 | 适用 |
|----|--------|---------|------|
| comfortable | 40px | ≥ 44px | 默认;通用工具 |
| compact | 32px | ≥ 36px | 数据密集(表格、IDE 类) |

同一产品选一档为默认;允许个别数据密集页局部降为 compact,不允许同页混档。

### 对齐法则

- 页面容器统一 padding,子元素不再叠加水平 padding(否则对不齐)
- kicker/meta 小标签在主标题**上方**(上下结构),不压成左右两列
- 子元素间距用 grid gap / flex column + gap,**禁用**逐个 margin-top 硬堆
- 内容预留安全区,不贴窗口边缘

## 组件规范

### 卡片四类(互斥,不能混用)

| 类型 | 类名 | 角色 | 软件用法 |
|------|------|------|---------|
| Ink 黑底 | `card-ink` | 反转 / 宣言 | 欢迎页、强调块 |
| Accent 填充 | `card-accent` | **唯一焦点** | 一屏内只允许一张(当前重点/主 CTA) |
| Grey 灰底 | `card-fill` | 默认中性 | 多卡并列、统计卡、设置分组 |
| 描边 | `card-outlined` | 锚点(非卡片) | hairline 分割框 |

❌ 禁止混用(蓝底+蓝描边、灰底+描边等)。多卡并列用同一类(优先 card-fill),只突出一项时单独换 card-accent。

### 按钮 / 输入 / 控件

- 直角无圆角;纯色填充或 hairline 描边,无阴影无渐变
- 高度:sm 32 / md 40 / lg 48;输入框与同排按钮等高对齐
- 主按钮:accent 填充 + accent-on 文字;次按钮:grey-1 或描边;破坏性操作用 error 填充,且仅此场景允许 error 填充
- 表单 label 在输入框上方左对齐;校验错误 = error hairline 描边 + 错误文案,不用弹窗报错

### 状态设计(软件核心,海报没有)

| 状态 | 规则 |
|------|------|
| hover | 底色 `--grey-1`;不位移、不缩放、不发光 |
| pressed | 底色加深一档(`--grey-2`) |
| focus(键盘) | 2px accent 外描边(offset 2px);任何元素不得移除焦点环,除非提供等价可见替代 |
| selected | accent 8% 底(`--accent-soft`)+ 左缘 2px accent 条,或 accent 文字 |
| disabled | 文字与边框 `--grey-2`;不响应 hover |
| loading | 优先骨架屏(`--grey-1` 直角块);按钮内可用 spinner |
| empty | 几何装饰(8×8 方块/描边圆)+ 一句话说明 + 一个主行动按钮 |

### 浮层与层级(软件独有)

- z 阶梯:dropdown 100 / sticky 200 / drawer 300 / modal 400 / toast 500
- 浮层是**全应用唯一允许阴影处**:单层 `0 8px 24px rgba(10,10,10,.12)` 与 hairline 描边二选一
- 菜单/弹窗/toast 保持直角 + `--paper` 底;toast 用 ink 黑底白字,不用彩色

### 表格(软件独有)

- 表头:Meta 档字重 600 + `--grey-1` 底;行 hairline 分割;行 hover `--grey-1`
- 数字列右对齐 + mono;主文本列左对齐;操作列靠右

### 导航(软件独有)

- 侧边栏选中项:accent 8% 底 + 左缘 2px accent 条(或 accent 文字)
- Tab 选中:底部 2px accent 条;未选中 `--grey-3`
- 面包屑/辅助链接 `--grey-3`,hover 变 `--ink`

### 图表(数据驱动设计的灵魂)

- 条形图:1px 或 8px 宽的纯色条,直角,`transform-origin` 底部生长
- 用主 accent 单色系 + 灰阶层次,不用彩虹配色;多系列最多 4 色(accent、ink、grey-3、grey-2 按重要性排序)
- 数字用 mono 字体 + `tnum` 特性
- **有真实数据才用图表,禁止为概念编造数值**
- 深色模式下系列色同步提亮

### 图标

- 用 Lucide(棱角风格),不自绘 SVG 图标
- 尺寸三档 16/20/24;同一界面 stroke 统一(1.5 或 2)
- 装饰几何(点阵/描边圆/叉网格)只在欢迎页/空状态透出,工作区保持纯净
- 用 8×8 直角小方块替代圆点装饰;禁用 emoji 代替图标

### 动效

- 每处动效与图形语义耦合:数字 scale 弹入、bar scaleY 拉起、圆环 stroke-dashoffset 描线;**禁止**所有元素用同一个 fade-up
- 缓动:`cubic-bezier(.2,0,.38,.9)` 120-240ms(常规交互);`cubic-bezier(0,0,.3,1)` 400-700ms(欢迎页/引导)
- 软件附加:浮层进 150ms 出 100ms;视图切换 ≤ 200ms;列表增删用高度过渡,不闪跳
- `prefers-reduced-motion` 时关闭非必要动效

## 布局模式库(软件界面)

| 界面类型 | 推荐结构 |
|----------|---------|
| 列表 + 详情 | 左列表右详情,中间 1px 竖线 |
| 设置页 | 左锚点导航 + 720px 内容列,分组 card-fill |
| 数据表格 | 顶部筛选行(Meta 档)+ 全宽表 + 底部分页 |
| 仪表盘 | Display 级 KPI 大数字行 + 12 列图表网格 |
| 表单/向导 | 单列 480-720px,hairline 分组,主按钮随内容左对齐 |
| 登录/引导 | 分屏:左 ink/accent 半屏宣言大字,右表单列 |
| 空状态 | 整块垂直居中:几何装饰 + 一句话 + 主行动 |

## 图片与插画(软件语境)

- 头像/缩略图直角、无框、无阴影;照片 `object-fit:cover`
- 空状态/引导插画:几何形 + accent 单色,不用多彩卡通
- 营销/官网页可用摄影图;产品工作区内不放装饰大图

## 可访问性(软件必备,海报没有)

- 正文对比 ≥ 4.5:1,大字(≥ 24px)≥ 3:1;accent 底上的 accent-on 必须实测
- 键盘可达:所有交互元素 Tab 可达,焦点环可见,焦点顺序与视觉顺序一致
- 触控目标 ≥ 44×44(移动端);桌面可 32px
- 不用颜色作为唯一信息载体(错误同时有图标/文字)
- 尊重 `prefers-reduced-motion` 与系统深色模式

## 禁止清单(自查用)

- ❌ 衬线字体(任何衬线出现都是错的)
- ❌ 常规表面渐变/阴影/圆角(浮层单层阴影、头像/开关等强制圆形控件除外)
- ❌ 同一界面内多个焦点色并存;逐界面临时取色
- ❌ 语义色当装饰色或第二 accent
- ❌ 未 Token 化的硬编码色值/字号/间距
- ❌ 大字用 weight 600/700/800(越大越细,灵魂)
- ❌ 页面大标题 `text-align:center`(左对齐 + 非对称留白)
- ❌ 卡片混用填充类型
- ❌ emoji 代替 Lucide 图标
- ❌ 9px 圆形装饰点(用 8×8 直角方块)
- ❌ 文字 < 11px
- ❌ 移除焦点环且无替代;仅用颜色表达状态
- ❌ 装饰元素贴边或溢出页面

## Token 落地(一致性保障,新增)

所有视觉决策沉淀为 design token(推荐 CSS 变量),组件只引用 token:

```css
:root {
  /* 灰阶 */
  --paper:#fafaf8; --grey-1:#f0f0ee; --grey-2:#d4d4d2; --grey-3:#737373; --ink:#0a0a0a;
  /* 焦点色(示例:IKB) */
  --accent:#002FA7; --accent-on:#ffffff; --accent-soft:rgba(0,47,167,.08);
  /* 语义色 */
  --success:#1A7F37; --warning:#9A6700; --error:#B42318;
  /* 字体 */
  --font-sans:"Inter","Helvetica Neue","Segoe UI",system-ui,sans-serif;
  --font-mono:"JetBrains Mono","Cascadia Code",Consolas,ui-monospace,monospace;
  /* 间距(8px 基线) */
  --sp-1:4px; --sp-2:8px; --sp-3:12px; --sp-4:16px; --sp-6:24px; --sp-8:32px; --sp-12:48px;
  /* 层级 */
  --z-dropdown:100; --z-sticky:200; --z-drawer:300; --z-modal:400; --z-toast:500;
  /* 浮层阴影(唯一允许的阴影) */
  --shadow-float:0 8px 24px rgba(10,10,10,.12);
}
```

- 字号阶梯、控件高度、圆角(=0)同样 Token 化;深色模式只需覆盖色值组
- 审查时 grep 硬编码 hex/px 即可发现违规

## 给 AI 编码代理的执行指引(OpenCode / Claude Code 等)

1. 本文档是唯一视觉规范:先通读"设计哲学 + 禁止清单",再按"Token 落地"建 Token,最后逐界面套组件
2. 视觉重设计只改表现层(布局、样式、层级、文案措辞),不得改动业务逻辑、接口与数据结构
3. 逐界面推进:每个界面自查"哲学 7 条 + 禁止清单"通过后再进入下一个
4. 两难时选"更克制、更扁平、更左对齐"的方案
5. 完成后五项必查:深色模式、键盘焦点可达、< 11px 文字、同屏多焦点色、硬编码魔法值

## 快速应用流程

1. **确认平台与密度**:桌面/移动;comfortable/compact
2. **定 Token**:灰阶 + 主 accent(4 套预设选一,或品牌色规范化)+ 语义色 + 字号阶梯
3. **搭骨架**:12 列 grid + 8px 基线 + 导航/内容框架
4. **逐界面套组件**:卡片四类互斥、状态齐全、图表只用真数据
5. **深色模式 + 可访问性自检**
6. **过一遍禁止清单**
